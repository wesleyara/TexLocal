# 11. Commits

- Status: aceito
- Data: 2026-11-09
- Referência: D11 em [decisoes.md](../backlog/decisoes.md)

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Commits**, tomada na sessão de sabatina inicial.

## Decisão

**Auto-checkpoint** após inatividade com mudanças + **versões nomeadas** (tags anotadas)

## Alternativas consideradas

- Só manual
- commit por compilação

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
