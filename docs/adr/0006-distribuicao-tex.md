# 6. Distribuição TeX

- Status: aceito
- Data: 2026-11-09
- Referência: D06 em [decisoes.md](../backlog/decisoes.md)

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Distribuição TeX**, tomada na sessão de sabatina inicial.

## Decisão

**TeX Live gerenciado** pelo app (instalação no diretório de dados do usuário, `tlmgr` para pacotes); usa TeX do sistema se detectado e o usuário preferir

## Alternativas consideradas

- Tectonic
- híbrido

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
