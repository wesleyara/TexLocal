# 5. Plataformas

- Status: aceito
- Data: 2026-11-09

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Plataformas**, tomada na sessão de sabatina inicial.

## Decisão

## Alternativas consideradas

- Linux primeiro

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
