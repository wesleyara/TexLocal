# 10. Git

- Status: aceito
- Data: 2026-11-09
- Referência: D10 em [decisoes.md](../backlog/decisoes.md)

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Git**, tomada na sessão de sabatina inicial.

## Decisão

**Git embutido** (crate `git2`/libgit2, sem exigir git no sistema). Local + remotos + branches básicos

## Alternativas consideradas

- Só local
- cliente completo com rebase/stash

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
