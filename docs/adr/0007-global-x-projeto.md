# 7. Global x projeto

- Status: aceito
- Data: 2026-11-09
- Referência: D07 em [decisoes.md](../backlog/decisoes.md)

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Global x projeto**, tomada na sessão de sabatina inicial.

## Decisão

**Instalação TeX global compartilhada** + **manifesto `texlocal.toml` por projeto** (motor, ano do TeX Live, pacotes extras, arquivo principal), versionado no git

## Alternativas consideradas

- Árvore TeX isolada por projeto

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
