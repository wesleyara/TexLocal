# 17. Recursos de projeto no MVP

- Status: aceito
- Data: 2026-11-09
- Referência: D17 em [decisoes.md](../backlog/decisoes.md)

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Recursos de projeto no MVP**, tomada na sessão de sabatina inicial.

## Decisão

Templates (incl. ABNT/abntex2), bibliografia (.bib, `\cite`, BibTeX/biber, DOI), outline + `\ref`/`\label` + multi-arquivo, corretor ortográfico (Hunspell pt-BR/en)

## Alternativas consideradas

- Nenhuma alternativa registrada.

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
