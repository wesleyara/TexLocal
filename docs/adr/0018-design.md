# 18. Design

- Status: aceito
- Data: 2026-11-09
- Referência: D18 em [decisoes.md](../backlog/decisoes.md)

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Design**, tomada na sessão de sabatina inicial.

## Decisão

**IDE moderna**: escuro por padrão (com tema claro), densa, command palette central. Layout: activity bar · sidebar · editor · PDF

## Alternativas consideradas

- Editorial
- minimalista

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
