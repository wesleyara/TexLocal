# 13. Auth remota

- Status: aceito
- Data: 2026-11-09
- Referência: D13 em [decisoes.md](../backlog/decisoes.md)

## Contexto e problema

Decisão de produto/arquitetura do TexLocal sobre **Auth remota**, tomada na sessão de sabatina inicial.

## Decisão

**OAuth device flow (GitHub/GitLab)**, **PAT** e **SSH**; segredos no keyring do SO

## Alternativas consideradas

- Nenhuma alternativa registrada.

## Consequências

Esta decisão orienta as histórias dos épicos relacionados; mudanças exigem um novo ADR que substitua este.
